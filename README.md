# 時間地図・運賃地図

中心駅からの「所要時間」または「運賃」で駅の位置を歪めて表示します。駅の方角は地図と同じままです。

| モード | 中心駅からの距離 |
|---|---|
| 実地図 | 地図上の距離。緯度経度をそのまま投影するので、地図と同じ配置になります |
| 時間地図（100%） | 中心駅から電車でかかる時間に比例 |
| 運賃地図（100%） | 中心駅からの運賃（IC運賃）に比例 |

歪み強度が 0〜100% の間では、実距離と時間（運賃）の距離を線形に混ぜます。100% のときは「○分／○円」の同心円が表示されます。駅または駅名をクリックすると、その駅が中心駅になります。凡例の路線名をクリックすると、その路線の表示・非表示を切り替えられます。
