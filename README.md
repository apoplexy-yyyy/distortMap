# 時間地図・運賃地図

中心駅からの「所要時間」または「運賃」で駅の位置を歪めて表示します。駅の方角は地図と同じままです。

| モード | 中心駅からの距離 |
|---|---|
| 実地図 | 地図上の距離。緯度経度をそのまま投影するので、地図と同じ配置になります |
| 時間地図（100%） | 中心駅から電車でかかる時間に比例 |
| 運賃地図（100%） | 中心駅からの運賃（IC運賃）に比例 |

歪み強度が 0〜100% の間では、実距離と時間（運賃）の距離を線形に混ぜます。100% のときは「○分／○円」の同心円が表示されます。対象は京急線・横浜市営地下鉄（ブルーライン・グリーンライン）・金沢シーサイドライン・みなとみらい線・東急東横線（渋谷〜横浜）・東急新横浜線（日吉〜新横浜）・相鉄線（本線・いずみ野線・相鉄新横浜線）・JR横須賀線（品川〜久里浜）・JR根岸線（横浜〜大船）・JR横浜線（東神奈川〜八王子）・JR東海道線（品川〜辻堂）です。駅または駅名をクリックすると、その駅が中心駅になります。凡例の路線名をクリックすると、その路線の表示・非表示を切り替えられます（隠した路線だけの駅と線を消します。乗換駅は他の路線が出ていれば残ります。中心駅は常に表示）。

## GitHub Pages での公開
リポジトリの Settings → Pages で「Deploy from a branch」・`main`・`/ (root)` を選ぶと、`https://<ユーザー名>.github.io/distortMap/` で開けます（`data/*.js` も入っているので、そのまま動きます）。

- GitHub Pages ではサーバー側のプログラム（`serve.py`）が動かないので、ランドマークをマイマップの URL から読むことはできません。`data/landmark_presets.js` に登録して `python build_landmarks.py` で取り込んだマイマップ（`data/landmarks_kml.js`）と、KML ファイルの読み込みは使えます。マイマップを編集したら `build_landmarks.py` を実行してコミットしてください。
- データを作り直したら（`build_*.py`）、`data/*.js` をコミットして push すると Pages にも反映されます。
- 手元で Pages と同じ条件で確かめるには `python -m http.server 8091`（`serve.py` の取り次ぎなし）で開きます。
- **注意**: `data/*.js` は各社の時刻表・運賃表から作ったデータです。各社のサイトの利用規約では転載・再配布が禁止されているものがあり（JR東日本・東急・相鉄・みなとみらい線など）、公開は規約に反するおそれがあります。公開は自己責任で行い、問題があれば非公開にしてください。

## データの準備
このリポジトリには、各社のサイトから取得した時刻表・運賃表の原本は入っていません（各社のサイトの利用規約で転載・再配布が禁止されているため）。生成したデータ（`data/*.js`）は入っていますが、作り直すときは自分で取得してください（取得は個人で使う範囲にとどめてください）。

```

node download_keikyu.js          # keikyu_pdf/ に京急の運賃表・時刻表
python build_keikyu.py           # data/keikyu.js
python build_yokohama.py         # data/yokohama.js（下の「横浜市営地下鉄」の節を参照）
python build_seaside.py          # data/seaside.js
python build_minatomirai.py      # data/minatomirai.js
python build_tokyu.py            # data/tokyu.js
python build_sotetsu.py          # data/sotetsu.js
python build_jr.py               # data/jr.js
python build_landmarks.py        # data/landmarks_kml.js（index.html を直接開くときのランドマーク）
python serve.py                  # http://localhost:8090/ で表示
```

- 手で置くファイル: 横浜市営地下鉄の運賃表 `yokohama_pdf/fare.pdf`、シーサイドラインの運賃表 `seaside_pdf/commuter_pass_normal1.pdf`（URL は各節を参照）。
- 横浜市営地下鉄の時刻表は ODPT のアクセストークンが要ります（`.odpt_token` に置く。リポジトリには入れない）。
- 時刻表の版（JR の `TIMETABLE_EDITION`、東急の `EDITION`、ODPT の `GTFS_DATE` など）は取得時点のものです。各社のダイヤ改正に合わせて直してください。

## 表示の共有（URL）
今の表示の状態は、ページの URL の `#` 以降に入っています（操作するたびに更新）。「共有」ボタンで URL をコピーでき、その URL を開くと同じ表示になります。

| 項目 | URL での書き方 |
|---|---|
| モード | `m=distance`（実地図）・`m=time`（時間地図）・`m=cost`（運賃地図） |
| 歪み | `s=0〜100`（%） |
| 中心駅 | `c=駅名` |
| 2D / 3D | `v=2d`・`v=3d` |
| 背景地図の濃さ | `bg=0〜100`（%） |
| 隠した路線 | `hide=京急線,JR横浜線`（凡例の名前。徒歩連絡は `徒歩`） |
| 表示中のランドマーク | `lm=マイマップのmid,…`（KML ファイルから読んだ地図は入りません） |
| 拡大・移動（2D） | `z=拡大率,横,縦` |

- 他の人と共有するには、相手もこのアプリを開ける必要があります（`index.html` をダブルクリックで開いた URL は自分のパソコンのファイルを指すので、相手のパソコンでは同じ場所にアプリを置いたときだけ開けます）。
- 3D の視点（カメラの向き）は URL に入りません。

## 時間と運賃の組み合わせ
- 経路がいくつかあるときは、**最も速い経路の時間と、その経路の運賃**を使います（同じ速さなら安い方）。たとえば新杉田→金沢八景は、シーサイドライン（316円）より速い「杉田まで歩いて京急」（16分・228円）になります。
- 運賃は事業者ごとに数えます。同じ事業者の列車を乗り継ぐ区間は 1 回の乗車として、乗った駅から降りた駅までの運賃にし、事業者が変わるたびに足します。
- 時刻表のない区間（今は横浜市営地下鉄）を通る駅は、経路が決められないので、最も安い運賃（乗換は何回でも）を使います。ツールチップに「時刻表なしのため最安の運賃」と出ます。

## 3D 表示
「表示: 3D」を選ぶと立体で表示します（初期値は 2D）（`view3d.js`、three.js を使用）。

- 水平面（東西・南北）は選んだモード（実地図・時間地図・運賃地図）の配置、高さは常に中心駅からの実際の距離（km）です。中心駅より北の駅はプラス（上）、南の駅はマイナス（下）になります。中心駅を通る上下の軸に「北10km」「南10km」などの目盛りがあり、床の同心円はモードの値（分・円・km）です。
- 背景地図も同じ規則で立体になります。中心駅を通る東西の線を境に、北側は上へ、南側は下へ分かれます（境目では高さが飛ぶので地図に切れ目ができます）。
- 左ドラッグで回転、右ドラッグで移動、ホイールで拡大縮小。駅または駅名のクリックで中心駅になります。
- 「表示: 2D」で従来の平面表示に戻せます。

## 背景地図
背景には国土地理院の地理院タイル（淡色地図）を表示し、駅と一緒に歪めます（`basemap.js`）。「背景地図」のスライダーで濃さを変えられます（初期値 50%、0% で非表示。3D 表示にも反映）。表示にはインターネット接続が必要です。

- 地図の各点は、中心駅からの方角はそのままで、距離だけを伸び縮みさせます。伸縮率は近くの駅の伸縮率（歪めた後の距離 ÷ 実際の距離）を、距離が近いほど重く混ぜたものです。そのため駅の位置では地図と駅がほぼ一致します。
- 時間・運賃データのない駅は、歪め方の計算に使いません。
- 運賃地図では、隣の駅でも最低運賃がかかるため、中心駅のまわりが大きく引き伸ばされます（地図がぼやけて見えます）。

## ランドマーク（Google マイマップの地点）
ボルダリングジムなど、駅以外の場所を地図に重ねられます（`landmarks.js`）。操作バーの「ランドマーク」ボタンで設定パネルが開きます。

- **読み込み方**
  - **既定の一覧から選ぶ**: `data/landmark_presets.js` に登録したマイマップがパネルに並ぶので、チェックすると読み込みます。
    登録したら `python build_landmarks.py` を実行して KML を取り込んでおくと（`data/landmarks_kml.js`）、`index.html` をダブルクリックで開いたときも読めます。マイマップを編集したら、もう一度実行してください。
  - **URL を貼る**: Google マイマップの URL（`https://www.google.com/maps/d/edit?mid=…` など、`mid=` を含むもの）を貼って「追加」。
  - **KML ファイル**: マイマップのメニュー →「KML/KMZ にエクスポート」で「KML にエクスポート（.kml）」にチェックして書き出したファイルを、パネルにドロップするか「KML ファイルを読み込む」で選ぶ。共有したくない地図はこちら。
- マイマップは「リンクを知っている全員が閲覧可」で共有してください。ブラウザから Google を直接読むことはできないので、
  - `python serve.py` で開いているとき … `serve.py` が最新の KML を取り次ぎます（パネルに貼った URL も読めます）
  - `index.html` をダブルクリックで開いたとき … `build_landmarks.py` で取り込んだ既定のマイマップだけ読めます。パネルに貼った URL は読めないので、`data/landmark_presets.js` に登録して `build_landmarks.py` を実行するか、KML ファイルで読み込んでください
- Google マップの「保存済み」のリスト（行ってみたい など）は座標を取り出す方法がないので使えません。マイマップに入れてください。
- 地図ごと・レイヤーごとに表示を切り替えられます。開いたときは地図はすべてチェックなし（共有 URL で指定された地図だけ表示）です。読み込んだ地点とレイヤーの設定はブラウザに保存されるので、2 回目からはすぐ表示されます。マイマップを編集したら「再読み込み」を押してください。
- **位置**: 背景地図と同じ歪め方で置くので、時間地図・運賃地図でも駅・地図とずれません（菱形の記号。3D では四角錐）。
- **時間・運賃**: 近くの駅（直線 1.5km 以内の 3 駅まで。無ければ最も近い駅）まで歩くとして、「中心駅からの時間＋徒歩時間」が最も短い駅を使います。徒歩時間は直線距離の 1.3 倍を分速 80m で歩くとして計算します（`app.js` の `WALK_DETOUR`・`WALK_M_PER_MIN`）。記号にカーソルを乗せると「中心駅から ○分 / ○円（○○駅から徒歩 約○分）」が出ます。
- 記号をクリックすると、その最寄り駅が中心駅になります。

## 京急の時間・運賃（時刻表・運賃表 PDF から）
京急の駅どうしの時間・運賃は、京急公式の PDF から作った `data/keikyu.js` を使います。

```
node download_keikyu.js   # keikyu_pdf/ に運賃表と各駅時刻表（KK01〜KK72）を保存
pip install pymupdf
python build_keikyu.py    # data/keikyu.js を生成
```

- **運賃**: 普通旅客運賃表【IC運賃】おとな の全 2628 区間（泉岳寺を含む 73 駅）。
- **時間**: 各駅の平日時刻表から発車時刻と種別（数字の色: 快特・特急・急行・普通）を読み取り、同じ種別の列車が次に停まる駅の発車時刻とつないで列車を復元しています（約 2900 本）。
  - アプリでは、中心駅を 10〜15 時台に出る列車で乗り継ぎも含めた最早到着時刻を計算し、各時台の最短所要時間の中央値を「時間」とします。
  - 時刻表は分単位の発車時刻なので、到着は発車の 30 秒前とみなしています。終点の到着時刻は同じ区間を走る他の列車の所要時間から推定しています。

## 金沢シーサイドラインの時間・運賃
`data/seaside.js` を `build_seaside.py` で作ります。

```
python build_seaside.py   # data/seaside.js を生成
```

- **運賃**: `seaside_pdf/commuter_pass_normal1.pdf`（普通旅客運賃表・大人 IC 運賃。ファイル名は定期券ですが中身は普通運賃と営業キロ）の全 91 区間。
- **時間**: 各駅の時刻表ページ（平日）を 2 秒間隔で 1 回だけ取得して `seaside_html/` に保存し、以後はそれを使います（取り直すときはフォルダを消して再実行）。全列車が各駅停車で追い越しもないので、隣の駅の発車とページに載っている駅間の運転時分（目安）でつないで列車にしています（平日 327 本）。「●」の付いた列車は並木中央止まりとして扱います。
- 京急とは金沢八景で乗り換えます（乗換時間 4 分）。JR 根岸線とは新杉田で乗り換えます（5 分）。
- 京急の杉田とシーサイドラインの新杉田は、徒歩連絡（7 分）でつないでいます。地図では灰色の点線で表示し、運賃は「歩く前の路線の運賃＋歩いた後の路線の運賃」で計算します。徒歩連絡は `app.js` の `WALK_TRANSFERS` で追加・変更できます。

```
pip install pymupdf
python build_sotetsu.py   # data/sotetsu.js を生成
```

- **時間**: 平日ダイヤの列車時刻表（上り・下り）。PDF は文字として読めるので、左の駅名の行と上の列車番号の列から各時刻の駅と列車を決めます（平日 802 本）。JR・東急への直通区間の駅は使いません。
- **運賃**: 普通旅客運賃表（大人）の IC カード運賃（三角形の表の右上、全 351 区間）。羽沢横浜国大・新横浜の加算運賃も含まれています。
- **乗り継ぎ**: 横浜（6 分）、湘南台（ブルーライン）・新横浜（JR 横浜線・ブルーライン）（5 分）で乗り換えます。新横浜で東急新横浜線と直通します（乗換時間 0 分）。
- 相鉄のサイトでは、私的使用の範囲を超えた転載・複製などが禁止されています。取得したファイルと `data/sotetsu.js` は個人で使う範囲にとどめてください。

## 東急東横線（渋谷〜横浜）・東急新横浜線（日吉〜新横浜）の時間・運賃
`data/tokyu.js` を `build_tokyu.py` で作ります。

```
pip install pymupdf
python build_tokyu.py   # data/tokyu.js を生成
```

- 東急電鉄の「各駅時刻表（PDF版）」（https://www.tokyu.co.jp/railway/timetable/ ）から東横線 21 駅の PDF を 2 秒間隔で 1 回だけ取得し、`tokyu_pdf/` に保存して以後はそれを使います。東急新横浜線の 3 駅（新横浜・新綱島・日吉）の PDF も同じように使います。ファイル名の `_1` が上り（渋谷方面）、`_2` が下り（横浜・新横浜方面）です。渋谷の `_1`（副都心線）と横浜の `_2`（みなとみらい線）は使いません。ダイヤ改正で PDF が変わったら、`build_tokyu.py` の `EDITION` を直して `tokyu_pdf/` を消してください。
- **時間**: PDF の数字は図形なので、図形の形で数字を読み、表のマスごとに 1 つの時刻にします。種別はマスの中の色・形で見分けます（赤い数字 = 急行、橙の四角 = 特急、橙の三角 = 通勤特急、黒 = 各停。平日のみ）。
  - 種別ごとの停車駅は時刻表から決め、次の停車駅の発車とつないで列車にしています（平日 東横線 852 本・東急新横浜線 334 本）。東横線と東急新横浜線は路線ごとに列車を作り、日吉で直通する列車は乗換時間 0 分でつなぎます。
  - 終点（下りの横浜・上りの渋谷）の到着時刻は、各停の所要時間から推定しています。
- **運賃**: 東急の運賃表（https://www.tokyu.co.jp/railway/ticket/fares/ 、営業キロ帯ごとの IC 運賃）と、Wikipedia「東急東横線」「東急新横浜線」の営業キロから計算します（東急の全駅どうし 253 区間）。東横線と東急新横浜線を乗り継ぐ場合も 1 回の乗車として、日吉で営業キロを足して数えます。新横浜で乗り降りする（新綱島〜新横浜を通る）場合は加算運賃（大人 70 円、運賃ページから読み取り）を足します。
- **乗り継ぎ**: 横浜で他の路線と乗り換えます。みなとみらい線（横浜）・相鉄線（新横浜）とは直通運転なので乗換時間 0 分としています（運賃は各社の合計）。菊名（JR 横浜線）は 3 分、日吉（グリーンライン）は 5 分、武蔵小杉（JR 横須賀線）は駅が離れているので 10 分です（`app.js` の `TRANSFER_MIN`・`PAIR_TRANSFER_MIN`）。
- 東急のサイトでは、私的使用の範囲を超えたコンテンツの利用（複製・頒布・アップロードなど）が禁止されています。取得したファイルと `data/tokyu.js` は個人で使う範囲にとどめてください。

## みなとみらい線の時間・運賃
`data/minatomirai.js` を `build_minatomirai.py` で作ります。

```
pip install pymupdf
python build_minatomirai.py   # data/minatomirai.js を生成
```

- 横浜高速鉄道の各駅ページ（https://www.mm21railway.co.jp/sp/station/ ）から、時刻表 PDF と運賃ページを 2 秒間隔で 1 回だけ取得し、`mm_pdf/`・`mm_html/` に保存して以後はそれを使います。
- **時間**: 時刻表 PDF の数字は文字ではなく図形なので、図形の形で数字を、色で種別（各停・急行・特急系）を読み取ります（平日のみ）。同じ種別の列車が次に停まる駅の発車とつないで列車にしています（平日 595 本）。
  - 急行は新高島を通過、特急系は新高島を通過（馬車道・日本大通りも通過する列車と停まる列車があります）。時刻表から読み取った停車駅をそのまま使います。
  - S-TRAIN は座席指定券が必要なので使いません（平日の時刻表には載っていません）。
  - 終点（元町・中華街行きの元町・中華街、横浜方面の横浜）の到着時刻は、各停の所要時間から推定しています。
- **運賃**: 各駅の運賃ページの IC カード運賃（全 15 区間）。
- 他の路線とは横浜で乗り換えます（6 分）。元町・中華街と JR 根岸線の石川町は徒歩連絡（約 500m、8 分）でつないでいます。
- サイトポリシーでは内容の無断転載が禁止されています。取得したファイルと `data/minatomirai.js` は個人で使う範囲にとどめてください。

## JR横須賀線（品川〜久里浜）・根岸線（横浜〜大船）・横浜線（東神奈川〜八王子）・東海道線（品川〜辻堂）の時間・運賃
`data/jr.js` を `build_jr.py` で作ります。

```
python build_jr.py   # data/jr.js を生成
```

- **時間**: JR東日本の列車時刻表（平日）を 1 回だけ取得して `jr_html/` に保存し、以後はそれを使います。列車ごとに各駅の時刻が載っているので、対象区間の停車駅をそのまま使います。
  - 横須賀線: 総武線快速・横須賀線の下り `222d1.html`・上り `222u1.html`（品川〜久里浜、308 本）
  - 根岸線: 京浜東北線・根岸線の南行 `623d1.html`・北行 `623u1.html`（横浜〜大船、554 本。横浜線から直通する列車も含みます）
  - 横浜線: 横浜線の下り `608d1.html`・上り `608u1.html`（桜木町・横浜〜八王子、325 本。快速を含みます）。東神奈川〜横浜〜桜木町の直通区間も横浜線の列車として使います（京浜東北線の東神奈川〜横浜は入っていません）

  - 普通・快速（「快速 ラビット」「特別快速」など料金の要らないものを含む）だけを使います。特急（料金が必要）、特定の日だけ走る列車（◆）、日付限定の時刻変更（時変）の列は除きます。

## 横浜市営地下鉄の時間・運賃
`data/yokohama.js` を `build_yokohama.py` で作ります。

```
pip install pymupdf pillow numpy
python build_yokohama.py   # data/yokohama.js を生成
```

- **運賃**: `yokohama_pdf/fare.pdf`（横浜市交通局「普通旅客運賃表」）。PDF は画像なので数字の形から読み取り、表の右上（IC運賃）と左下（きっぷ運賃）が対応しているかで全 780 区間を検証しています。
- **時間**: 公共交通オープンデータセンター（ODPT）の「横浜市営地下鉄」GTFS（https://ckan.odpt.org/dataset/yokohama_municipal_train ）を使います。平日ダイヤの全列車（2025-12-26 版で 705 本、快速を含む）を取り込みます。快速が通過する駅（時刻の無い行）は使いません。
  - `yokohama_gtfs/` に zip が無いときは、ODPT のアクセストークンで自動で取得します。トークンは環境変数 `ODPT_TOKEN` か、ファイル `.odpt_token`（1 行目）に置いてください。**トークンは他の人に渡したり公開したりしないでください**（`.gitignore` で除外しています）。
  - 新しい版が出たら、`build_yokohama.py` の `GTFS_DATE` をデータカタログの最新の日付に直し、`yokohama_gtfs/` の古い zip を消して実行してください。手動でダウンロードした zip を置いてもかまいません。
  - 交通局の時刻表検索サイトは自動取得が禁止されているので使いません。
  - GTFS が無いあいだは、地下鉄の駅は運賃だけ表示され、時間地図では灰色になります。
- **京急との乗り継ぎ**: 同じ名前の駅（横浜・上大岡・弘明寺）で乗り換えます。乗換時間は横浜 6 分・上大岡 4 分・弘明寺 10 分（駅が離れているため）としています（`app.js` の `TRANSFER_MIN`）。運賃の決め方は下の「時間と運賃の組み合わせ」を参照してください。

## 駅・隣接関係（scrape.js）
駅の位置と隣接関係は `scrape.js` で集めて `data/network.js` に保存します。アプリは保存済みのファイルを読むだけで、API キーも通信も不要です。

以下の乗換案内からの時間・運賃の取得（`data/routes.js`）は、今はアプリでは使っていません。

```
node scrape.js --test     # まず 1 区間（金沢八景→横浜）だけ取得して、解析できるか確認
node scrape.js            # 中心駅（初期値: 金沢八景）から全駅への時間・運賃を取得
```

- **駅・隣接関係**: HeartRails Express（無料）から取得し、`data/network.js` に保存します。
- **時間・運賃**: Yahoo!乗換案内の検索結果ページを 3 秒間隔で取得・解析し、`data/routes.js` に保存します。
  - 検索条件は平日 10:00 発です。新幹線・有料特急・飛行機・バス・フェリーは使わず、運賃はきっぷの値段です。
  - 表示された経路のうち、最短の時間と最安の運賃を採用します。A→B と B→A は同じとみなします。
- そのほかのオプション
  - `--center 横浜,品川`: 中心駅を追加します。
  - `--all`: 全駅の組み合わせを取得します。駅数が多いと数時間かかります。
  - `--retry`: 失敗した区間を取り直します。
  - `--network-only`: 駅データだけを取り直します。
- 途中で止めても、次回は続きから再開します。
- 駅名を特定できずに失敗した場合は、`scrape.js` の `NAME_ALIASES` に Yahoo!乗換案内での駅名を書いて `--retry` してください。解析できなかったページは `data/debug/` に保存されます。
- 路線を変えるときは、`scrape.js` の `LINES` を編集してから `--network-only` を実行します。路線名は HeartRails の表記（例: `京急本線`、`横浜市ブルーライン`、`グリーンライン`）です。路線の一部だけを使うときは `LINE_SECTIONS` に区間の端の駅を書きます（JR横須賀線は品川から南だけ。根岸線は HeartRails でも横浜〜大船なので全区間）。HeartRails の駅の並びにない区間は `EXTRA_EDGES` で足します（横浜線の東神奈川〜横浜）。HeartRails に無い路線名を使うときは、`LINE_SECTIONS` の `hr` に HeartRails の路線名を書きます（東急新横浜線は「相模鉄道・東京急行電鉄」の新横浜〜日吉）。

※ 利用規約を確認のうえ、個人利用の範囲で使ってください。
